# 한국 주식시장 가치 팩터(B/M) 재현과 확장

한국 주식시장(코스피 + 코스닥, 2000.7 ~ 2026.9)에서 **가치 팩터(B/M)를 원본 데이터부터 직접 만들어** FnGuide가 공개한 팩터 지수와 비교하고, 다른 요인을 통제해도 가치 효과가 남는지, 무형자산을 반영하면 나아지는지, 다른 가치 지표로도 되는지를 분석한 프로젝트입니다.

> 원본 데이터(FnGuide DataGuide)는 이용 계약상 저장소에 포함하지 않았습니다. 코드와 결과 그래프만 있습니다.

## 데이터

- **출처:** FnGuide DataGuide 6 (엑셀로 받음)
- **종목:** 코스피 + 코스닥, 상장폐지 종목 포함, 일반기업 보통주 (4,077종목)
- **기간:** 1999-01 ~ 2026-10 (분석은 2000-07 ~ 2026-09, 315개월)
- **항목:** 월 수익률(배당 포함), 시가총액, 거래정지·관리종목·시장구분, 연간 재무제표, 업종, 52주 베타, 지수·금리·경제지표, FnGuide 팩터지수, 상장폐지 종목 일간 주가 등

### 단위 주의
수익률 = % (4.89 = 4.89%), 시가총액 = 백만원, 재무 = 천원, 거래대금 = 원, 금리 = 연율 %, 52주 변동성 = 소수 연환산

## 데이터 처리

DataGuide 엑셀은 위쪽에 머리글이 여러 줄 있고, 파일마다 형식(달력기준 넓은 표 / 회계기준 긴 표 / 특정시점)이 달라서 다음 단계로 정리했습니다.

1. **원본 캐시** (`01_cache_raw.py`): 엑셀을 머리글 없이 통째로 읽어 모든 셀을 문자열로 parquet에 저장
2. **파서** (`korea_parsers.py`, `02_parse_korea.py`): 행 번호를 고정하지 않고 A열에서 `코드`, `코드명`, `아이템명` 머리글을 찾아 위치를 정함. 형태별 함수로 숫자 변환·긴 표 변환
3. **상장폐지 수익률** (`02b_상폐수익률.py`): 월말 가격 기준이라 월 중간에 상폐되면 그달 손실(정리매매 폭락)이 빠짐 → 상폐 종목 일간 주가로 **마지막 거래일 주가 ÷ 직전 월말 주가 − 1**을 계산해 상폐 다음 달 수익률로 넣음 (1,270종목, 평균 −37%, 중앙값 −9%)
4. **합치기** (`04_merge_korea.py`): 월별 패널, 연간 재무, 분기 실적, 시장 시계열, FnGuide 팩터지수 5개 표로 정리하고 열 이름을 한국어로 통일
5. **검증** (`03_verify_korea.py`, `05_verify_merge.py`): 원본 엑셀과 대조한 확인 항목 32개씩 통과

### 미래 정보 차단
- 재무제표는 **회계연도 말 + 6개월 뒤부터** 사용 (12월 결산 → 다음 해 6월 말부터)
- 결산월이 다른 회사 처리: 결산월이 1월부터 5월이면 회계연도 Y가 Y+1년에 끝나고, 6월부터 12월이면 Y년에 끝남 (Compustat과 같은 규칙)
- 포트폴리오는 t월 말 정보로 구성하고 **t+1월 수익률**로 평가
- 무위험 수익률은 **전월 말** CD 91일 금리 ÷ 12

### 분석 대상
코스피·코스닥(시장구분 KS, KQ)만, 거래정지·관리종목·스팩 제외, 장부가 > 0. 금융업은 포함(Fama-French 방식)

## 분석 방법

| 방식 | 내용 | 코드 |
|---|---|---|
| **2×3 HML** | 매년 6월 말 시가총액 중앙값(소형/대형) × B/M 30/70%(성장/중립/가치) = 6바구니, 7월 ~ 다음 해 6월 보유, 전달 말 시가총액 가중. B/M = 자본총계(지배) ÷ 전년 12월 시가총액. HML = (소형 가치 + 대형 가치)/2 − (소형 성장 + 대형 성장)/2 | `가치팩터(B-M) 재현.py` |
| **단순 롱숏** | 크기 구분 없이 B/M 상위 30% − 하위 30% (비교용) | 〃 |
| **순수 팩터 포트폴리오** | 매달 √시가총액 가중 횡단면 회귀: 다음 달 수익률 ~ 업종 10개 + 가치·크기·베타·모멘텀 z-score. 가치 계수 = 가치 노출 1, 나머지 노출 0인 포트폴리오의 수익률 (매달 코드에서 노출 확인). 가치 점수는 매달 최신 시가총액 기준 B/M | `가치팩터(B-M) 순수팩터.py` |
| **벤치마크 기울이기** | 비중 ∝ 시가총액 × max(0, 1 + k × 가치점수). 공매도 없는 현실 버전, 매년 6월 리밸런싱. k = 0.5 (추적오차 3%에 가장 가까운 강도) | `가치팩터(B-M) 벤치마크기울이기.py` |
| **네 가지 방식 비교** | 모든 전략을 연 변동성 10%로 맞춘 뒤 누적수익률 비교 (= 샤프 비교) | `가치팩터(B-M) 4가지비교.py` |
| **무형자산 조정 B/M** | 조정 장부가 = 자본총계(지배) + 지식자본(과거 R&D 누적, 연 15% 감가) + 조직자본(판관비의 30% 누적, 연 20% 감가). Eisfeldt·Kim·Papanikolaou (2022) 방법 | `가치팩터(무형자산조정) 확장.py` |
| **민감도 분석** | R&D 감가율 4가지 × 조직자본 감가율 3가지 × 판관비 비율 4가지 (서로 다른 조합 40개) | `가치팩터(무형자산조정) 민감도.py` |
| **다른 가치 지표** | 같은 2×3 틀로 E/P, CF/P, S/P, D/P, EBITDA/EV와 6개 순위 평균(종합 가치). 적자·무배당은 그 지표에서 제외 | `가치팩터(여러지표) 비교.py` |

통계: t = 월평균 ÷ (표준편차 ÷ √개월수), Newey-West t는 시차 5개월(floor(4 × (T/100)^(2/9))), 샤프 = 월평균 ÷ 월 표준편차 × √12 (롱숏은 무위험 수익률을 빼지 않음)

## 실행 방법

필요한 패키지: `pandas`, `numpy`, `pyarrow`, `python-calamine`, `matplotlib`

DataGuide에서 받은 엑셀을 `한국데이터/` 폴더에 넣고, 프로젝트 폴더에서 순서대로 실행합니다.

```
python scripts/01_cache_raw.py          # 엑셀 → 문자열 캐시 (처음엔 약 3분)
python scripts/02_parse_korea.py        # 파서로 정리 (약 2분)
python scripts/02b_상폐수익률.py         # 상장폐지 수익률 (04보다 먼저)
python scripts/03_verify_korea.py       # 검증
python scripts/04_merge_korea.py        # 5개 표로 합치기
python scripts/05_verify_merge.py       # 검증

python "scripts/가치팩터(B-M) 재현.py"
python "scripts/가치팩터(B-M) 순수팩터.py"          # 재현 다음에
python "scripts/가치팩터(B-M) 벤치마크기울이기.py"
python "scripts/가치팩터(B-M) 4가지비교.py"         # 위 세 개 다음에
python "scripts/가치팩터(무형자산조정) 확장.py"
python "scripts/가치팩터(무형자산조정) 민감도.py"   # 약 6분
python "scripts/가치팩터(여러지표) 비교.py"
```

Windows 터미널에서 한글이 깨지면 `PYTHONIOENCODING=utf-8`을 설정하고 실행하세요.

## 한계

- **거래비용 미반영:** 특히 순수 팩터는 매달 리밸런싱해서 실제 수익은 줄어듦
- **유동성:** 소형 가치주는 거래대금이 작아 큰돈을 넣기 어려움
- **공매도 제약:** 가치 프리미엄의 상당 부분이 공매도 쪽에서 나오는데, 한국은 공매도가 어렵고 금지 기간도 있었음
- **FnGuide와의 차이:** 2025년 이후 SK하이닉스 한 종목이 성장 바구니의 20% 가까이를 차지해 괴리가 커짐. FnGuide는 초대형주 비중을 다르게 처리하는 것으로 보임(미확인)
- **무형자산 가정:** 감가율·판관비 비율은 미국 연구에서 가져온 가정이라 민감도 분석으로 확인함
- 여러 가치 지표 중 가장 좋은 것을 고르면 과대평가될 수 있어, "대부분 통한다"를 결론으로 삼음
